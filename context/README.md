# Context packs: index

One line per pack. Load the specific pack a skill links to; do not bulk-load. Every pack carries a "Last reviewed" footer and a Primary sources section pointing at the official text. Regulations change: verify deadlines, thresholds and penalties against the official source before relying on them.
