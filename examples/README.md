# Worked Examples

Golden-path transcripts showing what the skills produce with realistic inputs. Each example names the persona and skill in play, shows the inputs an agent gathers, and reproduces the deliverable at the quality bar the skill's checklist enforces. All organizations, people, and incidents are fictional.

| Example | Persona | Skill exercised |
|---|---|---|
| [Incident notification decision](incident-notification-decision.md) | compliance-officer | [incident-regulatory-reporting](../skills/incident-regulatory-reporting/SKILL.md) |
| [Framework gap assessment (excerpt)](gap-assessment-excerpt.md) | grc-analyst | [framework-gap-assessment](../skills/framework-gap-assessment/SKILL.md) |
| [Vendor SOC 2 report review](vendor-soc2-review.md) | grc-analyst | [third-party-risk-assessment](../skills/third-party-risk-assessment/SKILL.md) |

Reproduce any of these by loading the persona (`agents/`), the skill's `SKILL.md`, and the context files the transcript references, then supplying the same inputs. See [docs/integrations/generic.md](../docs/integrations/generic.md) for the prompt-assembly recipe.
