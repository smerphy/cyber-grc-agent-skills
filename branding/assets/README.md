# Brand Assets

Drop your logo and image files here, then reference them from [../brand-profile.md](../brand-profile.md):

- `logo.svg` (preferred) or `logo.png` — primary logo for light backgrounds
- `logo-dark.svg` / `logo-dark.png` — variant for dark backgrounds (optional)
- Any other brand imagery deliverables should use (cover art, watermark, partner marks)

SVG scales cleanly in every output format; provide PNG at ≥600px width as a fallback. Nothing here is required — with no assets, deliverables use a text wordmark per the selected style spec.
